# Contributing to Vision360

First off, thank you for considering contributing to Vision360! 

## Getting Started

1. Fork the repository and clone it to your local machine.
2. Run `npm install` to install dependencies.
3. Create a new branch for your feature or bug fix: `git checkout -b feature/your-feature-name`.

## Development Guidelines

- **Code Style:** We use Prettier and ESLint. Please run `npm run format` and `npm run lint` before committing your changes.
- **Testing:** If you add new features, please write corresponding tests in the `tests/` directory. Run `npm run test` to verify your changes don't break existing functionality.
- **Commit Messages:** Use clear and descriptive commit messages.

## Submitting Pull Requests

1. Push your changes to your fork.
2. Open a Pull Request against the `main` branch of the upstream repository.
3. Ensure all CI checks (if any) pass.
4. Request a review from maintainers.
